# Gestión del Taller (PWA)
1. **Supabase**: crea proyecto → Authentication > Providers > Email: desactiva "Allow new users to sign up" → Users > Add user (jefe y jefa) → SQL Editor: ejecuta `schema.sql` (cambia antes los 2 correos).
2. Edita `config.js` con la URL y la clave *anon public*. Nunca la `service_role`.
3. GitHub: sube estos archivos a un repo → Settings > Pages > Deploy from branch `main` / root.
4. Abre la URL de Pages. En el móvil: menú del navegador > "Añadir a pantalla de inicio".
